# 风格关键词速查

风格词决定画面的"视觉流派"。本文档是可直接摘取的词表——挑 2–4 个相容的词组合即可，不需要全用。

**使用原则**

1. **少而准**：一个主风格 + 一个修饰风格通常最优。堆 8 个风格词会让模型平均化，输出反而平庸。
2. **先定介质，再定风格**：先明确"照片 / 插画 / 3D / 平面设计"，再在这条线上选具体流派，能避免串味。
3. **与负向词配套**：选定写实就要在负向里压 `cartoon, 3d render`；选定 2D 就要压 `photorealistic`。见 `negative-prompt.md`。

## 画质增强

超详细、8K、4K、高清细节、照片级真实、电影级质感、超高细节、影棚专业品质、原始细节、清晰锐利、无压缩痕迹

> 画质词只是"保底"，不产生风格。真正决定质感的是镜头、光线、材质描述。

## 镜头与器材

| 类型 | 关键词 | 效果 |
|------|--------|------|
| 广角 | 24mm、广角镜头、超广角 | 空间纵深强，边缘透视拉伸 |
| 标准 | 35mm、50mm | 接近人眼，纪实感 |
| 中长焦 | 85mm、135mm | 人像压缩感，背景分离好 |
| 微距 | 微距镜头、macro | 极近细节，浅景深 |
| 大光圈 | f/1.4、f/1.8、f/2.0 | 强虚化，主体突出 |
| 小光圈 | f/8、f/11 | 全景深，风景/建筑 |
| 快门 | 1/1000s 凝固、1/15s 拖影 | 运动凝固或流动感 |
| 感光 | ISO 100 纯净、ISO 800 颗粒 | 干净或胶片噪点 |
| 机位 | 平视、俯视、仰视、鸟瞰、贴地、过肩 | 权力关系与情绪 |
| 质感 | 胶片颗粒、HDR、柔焦、色差、镜头光晕、暗角 | 真实感或瑕疵感 |
| 胶片 | Kodak Portra 400、Fuji Pro 400H、CineStill 800T | 具体肤色与色调倾向 |

## 光线

- **自然光**：黄金时刻（golden hour）、蓝调时刻（blue hour）、柔和晨光、正午硬光、阴天散射光、窗光
- **人造光**：影棚柔光箱、环形灯、伦勃朗光（Rembrandt lighting）、蝴蝶光、分割光、逆光轮廓（backlit silhouette）、边缘轮廓光（rim light）
- **氛围光**：霓虹灯、体积光/光柱（volumetric light）、丁达尔光、烛光、屏幕冷光、舞台追光
- **光影结构**：高对比硬阴影、柔和渐变阴影、明暗交界清晰、单侧主光、双色色片灯（双色 gel 光）、地面反射光、水面倒影

> 光线是"廉价高收益"字段：加一句具体光位（如"右前方 45° 主光 + 左后方轮廓光"）比加 5 个画质词有效。

## 色彩与调色

| 名称 | 关键词 | 适用 |
|------|--------|------|
| 橘青调 | teal & orange、青橙对比 | 电影感、动作片 |
| 莫兰迪 | 莫兰迪色系、低饱和灰调 | 高级感、家居、女性向 |
| 复古褪色 | muted desaturated dusty tones、褪色胶片 | 怀旧、纪实 |
| 富士胶片 | 富士胶片风、青绿偏冷 | 日系写真、街拍 |
| 霓虹赛博 | 赛博朋克霓虹、洋红+青蓝 | 科技、夜城 |
| 高饱和 | 高饱和度、色彩清澈如宝石 | 动漫、壁纸 |
| 单色 | 黑白高对比、单色分离调（split toning） | 时尚、严肃题材 |
| 柔和粉调 | 奶油粉彩、pastel、粉蓝奶油色 | 少女、甜系、日常 |
| 自然真实 | 自然色彩平衡、无强调色 | 纪实、产品 |

## 构图与取景

- **景别**：极特写（extreme close-up）、特写、中景、全身、广角全景
- **视角**：平视、俯视（bird's eye）、仰视（low angle）、荷兰角倾斜、过肩视角
- **结构**：三分法、黄金比例、对称构图、对角线构图、框架式构图（frame within frame）、引导线
- **空间**：浅景深、深景深、前景虚化、负空间/留白、主体居中、主体偏置
- **版式**：纵向拼贴、宫格分镜、拉页全景、杂志跨页、海报竖版

> 需要给文字/UI 留位时，务必正向写明"左侧留出大面积负空间用于标题"——这比事后裁切可靠。

## 材质与质感

- **皮肤**：毛孔可见、细纹、真实肤色不均、汗珠、微光泽
- **织物**：亚麻纹理、牛津布织法、丝绸反光、针织毛圈、做旧磨损
- **金属**：拉丝金属、镜面反射、氧化痕迹、镀铬高光
- **玻璃**：厚玻璃折射、磨砂表面、边缘色散
- **自然**：湿润石面、苔藓、木纹年轮、雪面颗粒
- **食品**：酥脆断面、糖霜结晶、油脂光泽、水珠凝结
- **工业**：锈蚀、喷漆脱落、焊接痕、混凝土气孔

## 风格混搭与冲突

**相容组合（推荐）**

- 写实 + 电影感 + 橘青调（叙事海报）
- 时尚编辑 + 黑白 + 硬阴影（高级人像）
- 扁平插画 + 信息图 + 留白（知识图）
- 3D 动画 + 柔和光 + 粘土质感（儿童内容）
- 东方水墨 + 留白 + 宣纸（文化配图）

**冲突组合（避免）**

| 冲突 | 原因 |
|------|------|
| 照片级真实 + 动漫画风 | 介质互斥，输出会糊成半写实 |
| 极简留白 + 繁复巴洛克 | 构图指令自相矛盾 |
| 高饱和 + 低饱和 | 调色指令相互抵消 |
| 浅景深 + 全景深 | 景深指令冲突 |
| 写实 + 卡通渲染 + 3D | 三介质混杂，脸部最容易崩 |

> 需要真正的混搭（如"写实人物 + 插画背景"）时，明确**分区**："人物为真实摄影质感，背景为黑白漫画线稿"——分区混搭才可控。

## 各模型风格语法

| 模型 | 风格写法 |
|------|----------|
| Stable Diffusion / SDXL | 风格词前置或靠前，可用权重 `(oil painting:1.2)` |
| Flux | 用完整自然语言句子描述风格，权重语法无效 |
| Midjourney | 风格词 + 参数：`--ar 16:9 --stylize 250 --v 6.1 --style raw` |
| Niji（MJ 二次元） | `--niji 6`，配 `--stylize` 控制插画强度 |
| DALL·E 3 / GPT Image | 用一句话点明"以 X 风格呈现"，避免堆词 |
| Gemini / Nano Banana | 自然语言描述"像某类作品的样子"，可给参考流派名 |
| 即梦 / 可灵 / Seedream | 支持风格标签，接近 SD 系写法；权重与负向框支持情况以各平台文档为准 |
