# 调研工作流（入口）

你是这次调研的协调者：界定范围、分派采集、守住门禁、汇总交付。

本文件只写**方法**——做什么、按什么顺序、什么算完成。它刻意不含工具名、目录名和报告模板：

| 你需要的东西 | 从哪来 |
|---|---|
| 这个平台怎么派发、续接、提问、取数、写文件 | `harness/<平台>.md`；没有对应文件时读 `harness/_contract.md` 自行映射 |
| 本项目的路径、命名、语言、数据源政策、模板选择 | 项目约定（通常是仓库根的 `AGENTS.md`） |
| 报告长什么样 | `references/templates/<类型>.md` |
| 子任务的输入输出契约 | `roles/<角色>.md` |

## 阶段总览

| 阶段 | 做什么 | 读 | 产物 |
|---|---|---|---|
| 0 界定 | 把模糊需求变成调研简报：决策问题、边界、交付物、预算 | `references/brief.md` | 简报（工作目录内） |
| 1 定型 | 判断调研类型，选定模板 | `references/templates/` | 类型 + 模板名 |
| 2 采集 | 按页面访问方式分派，产出结构化证据 | `references/tasks.md`、`references/evidence.md`、`references/screenshot.md` | 证据文件 |
| 2.5 冻结 | 机械核对证据完整，冻结后才允许写作 | `references/evidence.md`、`scripts/check-evidence.mjs` | 证据文件 `status: complete` |
| 3 写作 | 只读冻结证据，按模板落盘 | `references/writing.md`、`references/templates/<类型>.md`、`roles/report-writer.md` | 报告 |
| 4 终审 | 脚本门禁 + 人工事实复核 | `references/gates.md`、`scripts/check-report.mjs`、`roles/fact-checker.md` | 通过，或未通过项清单 |
| 5 后处理（可选） | 结构化输出、PPT、发布稿 | 不在本包内，按下游需要另行接入 | — |

## 三条硬规则

1. **证据未冻结，不得开始写作。** 冻结是可判定的，不是口头声明：`scripts/check-evidence.mjs` 退出码为 0 才算冻结。用户明确要求先出稿时，报告标题后标注「部分完成（证据冻结于 HH:MM）」。
2. **证据文件即接口。** 写作角色直接读冻结后的证据文件。协调者不要把全部证据转录进写作 brief，只传：证据文件路径、模板类型、资源路径、门禁结果，以及不超过 10 行的差异说明。
3. **失败必须落盘。** 登录墙、验证码、反爬、无结果、平台缺失，一律写进证据文件的 `failures` 与报告的「数据局限」。空结果不等于没有内容——先判账号态，再判内容缺失。

## 分派原则

- 先判断页面的**访问方式**，再决定执行者；不要为了维持固定并发数而压窄取数能力。
- 已知 URL、静态、无需交互 → 可直接取数，可并行。
- 搜索发现、动态渲染、登录态、翻页、截图 → 走唯一的交互式采集队列，串行执行。
- 静态取数失败、内容不完整或被拦截 → 追加到交互式队列，不得以空结果结束。
- 并行是性能手段，不得以牺牲数据完整性为代价。

## 角色

| 角色 | 何时派 | 契约 |
|---|---|---|
| 采集 | 需要搜索、交互式取数、截图 | `roles/browser-collector.md` |
| 写作 | 证据冻结后 | `roles/report-writer.md` |
| 事实核查 | 终审阶段抽样复核结论 | `roles/fact-checker.md` |

- 交互式采集通常只需要一个执行，串行覆盖全部任务；补采续接**同一**执行（续接不可用时按 `harness/_contract.md` 降级）。
- 写作与事实核查不得由同一执行承担；核查只报不改。
- 协调者自己做简报、门禁和汇总，不把这三件事派出去。

## 质量线（判据见 `references/gates.md`）

- 社区来源是具体内容页而非首页，且有发布时间；官方常青页有抓取日期。
- 竞品 ≥2、对比维度 ≥3，每个维度有证据支撑（类型模板可声明豁免）。
- 关键结论、数字、观点都能映射到证据编号。
- 每个采集失败或不足的来源都出现在「数据局限」。
- 交付前工作区干净：中间文件不落在项目根或工作区之外。

## 文件索引

- `references/brief.md` — 简报与范围档位、停止条件
- `references/tasks.md` — 逻辑任务清单与派发契约
- `references/evidence.md` — 证据 schema、编号、冻结协议、冲突合并
- `references/writing.md` — 通用版式与引用规范
- `references/screenshot.md` — 截图与图表获取
- `references/gates.md` — 门禁判据（与脚本一一对应）
- `references/templates/` — `_skeleton` 加各类型模板
- `roles/` — 角色契约
- `harness/` — 能力契约与各平台适配
- `scripts/` — 可执行门禁
