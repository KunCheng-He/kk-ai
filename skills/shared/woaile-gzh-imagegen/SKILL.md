# 「我AI了」生图技能

为「我AI了」公众号生成品牌风格图片。本技能只负责**产出高质量提示词**（用户自行在浏览器生图），不生成图片本身。

## 品牌风格核心（一句话）

> **手绘感扁平插画：白底藏蓝描边、四色体系、气泡母题、小爱吉祥物、封面标题内嵌。**
> 知识传播场景另有融合变体：**手绘笔记本风知识科普图解**（暖纸底 + 藏蓝墨线 + 品牌淡色贴纸，详见 style-guide 第六节专章）。

风格唯一权威定义见 [references/style-guide.md](references/style-guide.md)（已含吉祥物 DNA、高级感手法、表格规范、提示词骨架）。

## 工作流程

1. **明确需求**：图片类型（封面 / 文章配图 / 图表配图 / 品牌化表格 / 知识科普图解）、比例（封面固定 2.35:1；配图按内容定）、文章主题与关键数据。涉及"一图读懂"、原理讲解、概念对比、流程拆解、趋势曲线时优先选**知识科普图解**。
2. **提炼主题符号**：给文章标题找一个"缩略图上 1 秒读懂"的视觉符号（新品→软件面板/工作台；对比→战列/天平；复盘→增长曲线等），先做缩略图测试：缩到 200px 还读得出主题吗？不行就重选符号。
3. **定小爱动作**：从 style-guide「吉祥物」章节选动作（讲解者/庆祝者/惊喜发现者），保证画面 10-25% 占比。
4. **组装提示词**：按 style-guide「提示词骨架」逐段填充。**以下段落必须原文粘贴，一字不改**：
   - 吉祥物「小爱」造型 DNA 段（style-guide 第三节代码块）
   - 品牌四色描述段（style-guide 第二节色板）
   - 高级感手法说明（style-guide 第五节，按本次选 1-3 种）
   - 文字约束（区分四类：插画=全禁；封面=只允许标题/副标签；表格=只允许表内文字；知识科普图解=只允许大标题/面板标题/条目/金句四类）
   - **知识科普图解改用 style-guide 第六节专属骨架**（暖纸底 + 藏蓝墨线 + 品牌淡色版），不适用通用骨架
5. **选择生图工具**：
   - **封面 & 插画配图**：豆包（视觉更饱满）或 Nano Banana（更稳定）；文字（标题/标签）要求精确时优先 Nano Banana，并上传 `assets/xiaoai-reference.jpeg` 作参考图，追加"保持图中角色的造型完全不变，只改变小爱的动作"。
   - **品牌化表格 & 知识科普图解**：**必须用 Nano Banana**（中文文字渲染最稳）；豆包易错字，仅作降级选择。知识图解还需同时上传对应版式样本（`references/samples/` 三选一）作风格参考。
6. **用户浏览器生图**：交付提示词，由用户在浏览器工具中生成（本技能不亲自生图，除非用户另有要求）。
7. **质检（逐项核对，不达标即迭代）**：
   - 文字校对：封面标题 / 表格与知识图解所有中文逐字检查，错字即重生成。
   - 四色检查：无色板外颜色（橙紫绿黄等一律不许；知识图解另允许暖纸底与品牌淡色版）。
   - 小爱一致：脸屏、爱心天线、胸口爱心、青绿耳、白身藏蓝描边是否保持（知识图解中为藏蓝手绘墨线版，DNA 不变）。
   - 密度与留白：表格占宽 ≥85%；知识图解面板组占画面 ≥80%；封面标题区无主体元素侵入。
   - 缩略图测试：主体轮廓与标题缩略可读。
8. **迭代修正规则**：只在提示词末尾**追加**修改点，前文不变；指令格式："保持其他内容不变，只把 X 改为 Y"，一次只改一处；连续 3 轮无效时回到步骤 2 换主题符号。
9. **定稿归档**：图片存入文章素材目录（`素材/` 子文件夹），提示词保存为 `*-prompt.md`（沿用公众号文章目录惯例），文件命名与正文引用对应。

## 图片类型与规格速查

| 类型          | 比例                    | 要点                                                                                                    |
| ------------- | ----------------------- | ------------------------------------------------------------------------------------------------------- |
| 封面图        | 固定 2.35:1（1800×766） | 标题内嵌左 1/3（≤10 字 + 珊瑚红爱心点睛）；主题符号清晰；可选扁平等轴视角                               |
| 插画/图表配图 | 按内容 16:9/4:3/长图    | 图表即插画（圆角柱/圆头折线/气泡节点）；小爱讲解；数据诚实                                              |
| 品牌化表格    | 16:9（2000×1125）       | 真实内容直接渲染；气泡形外框；表头 A（深藏蓝白字）/B（淡藏蓝藏蓝字）；表格占宽 ≥85%；重点行高亮双重锚定 |
| 知识科普图解  | 16:9（2000×1125）/3:4   | 手绘笔记本风：暖纸底 + 藏蓝墨线 + 品牌淡色贴纸；对比式/流程式/曲线式三版式；小爱涂鸦版点缀；文字四类硬限；必须 Nano Banana |
