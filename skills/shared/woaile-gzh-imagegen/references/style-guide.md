# 「我AI了」生图风格规范

> 本文是「我AI了」公众号专属生图风格的唯一权威定义。所有生图提示词必须从本文派生，不得凭空发挥。
> 风格来源：公众号 Logo（`~/Documents/wo-ai-le/0-logo设计/`）+ ai-bubble 排版主题（woaile-gzh-publisher）。

## 一、风格基因（从 Logo 提炼）

1. **对话气泡母题**：Logo 是一个手绘感对话气泡——不对称圆角（四角圆度略有差异）+ 左下弯钩尾巴。气泡是本公众号最强的视觉符号，生图时应作为核心母题反复出现（主角容器、背景元素、装饰点缀均可）。
2. **藏蓝粗描边**：Logo 轮廓为藏蓝粗线条，圆润闭合，线宽有手工呼吸感。所有画面主体元素应使用同款描边语言，让整张图像"从 Logo 里长出来的"。
3. **圆润字标**："Ai" 为圆润无衬线粗体——钴蓝 A、青绿 i、i 的点是珊瑚红爱心、右下角一枚珊瑚红圆点。这种"圆润 + 爱心 + 圆点"的俏皮感是情绪基调。
4. **纯白底、零渐变、零阴影**：排版主题的设计哲学，生图同样遵守。画面通透干净，靠留白而非装饰撑起质感。

一句话概括：**手绘感扁平插画，白底藏蓝描边，四色点缀，气泡母题，大留白。**

## 二、品牌色板（严格限色）

| 角色 | 色名 | 色值 | 用途 | 面积占比参考 |
|------|------|------|------|--------------|
| 主色 | 藏蓝 Navy | `#2d3773` | 描边、深色块、图形"文字"部分 | ~25-30% |
| 辅色1 | 钴蓝 Cobalt | `#2A6FF0` | 主角、科技物件、正向元素 | ~20-25% |
| 辅色2 | 青绿 Teal | `#1FC8C8` | 点缀、光效、成长/流畅暗示 | ~10-15% |
| 点睛 | 珊瑚红 Coral | `#FF5060` | 爱心、圆点、强调符号 | ≤10%，小而精 |
| 中性 | 白 / 浅雾蓝灰 / 深灰 | `#FFFFFF` / `#F5F7FA` / `#3F3F3F` | 背景、留白、次要细节 | 其余 |

限色纪律：
- 除上表外**不得引入其他色相**（橙、紫、绿、黄等一律不用）。
- 允许色板内做深浅微调（如藏蓝加深做层次、青绿淡化做背景晕染），但不得产生新色相。
- 珊瑚红永远做"点睛"：一颗爱心、一个圆点、一面小旗，绝不大面积铺陈。

## 三、吉祥物「小爱」（固定角色，必须复用）

公众号的固定吉祥物，独立于 Logo 之外的 IP 形象，取"AI = 爱"谐音梗。所有生图中的机器人**必须**是「小爱」，不得每次重新发明角色。

### 角色设定
- **名字**：小爱（AI = 爱）
- **性格**：热心、聪明、有点小得意的朋友感，永远温暖不说教

### 造型 DNA（提示词中原文复用下段）

```text
吉祥物「小爱」：一个二头身的圆润可爱小机器人，头大身小。白色胶囊形身体，藏蓝色(#2d3773)粗描边；头部正面是一块深藏蓝圆角方形"脸屏"，上面有两个白色点状眼睛和一个弧线微笑；头顶竖着一根短天线，天线顶端有一颗珊瑚红(#FF5060)小爱心；胸口有一枚发光的珊瑚红爱心指示灯（AI=爱的核心符号）；头部两侧是青绿色(#1FC8C8)圆形耳朵；短圆的手脚，整体 Q 版可爱、线条圆润、无复杂机械细节。
```

### 使用规则
- 小爱在画面中是**点缀与引导者**，不是喧宾夺主的主角：封面中占画面 15-25%，配图中可作讲解者（指向图表）、庆祝者（举手）、装饰（角落探头）。
- 表情系统：默认微笑；可变体眨眼、O 嘴惊讶、弯眼大笑，但造型 DNA 不变。
- 跨工具保持一致性：优先用已定妆的小爱图片作参考图（Nano Banana 上传参考图 + 提示词"保持这个角色的造型完全不变"）。

## 四、造型语言

- **圆润**：一切形状圆角化，无尖锐棱角；矩形一律大圆角。
- **不对称手工感**：允许微倾斜、粗细略变化的线条，避免机械完美对称——这是"手绘感"的来源。
- **描边统一**：所有主体元素统一藏蓝描边，宽度约为元素尺寸的 3-5%。
- **角色友好**：小爱之外的角色（人物、动物拟人）同样用点状眼、弧线嘴、圆腮红表达友善，不做复杂五官。
- **气泡变奏**：气泡可以直接当容器（气泡里装场景）、当角色（气泡长手脚）、当背景装饰（淡色大气泡衬底）。

## 五、高级感手法（与"简陋白底"的差距所在）

纯白底 + 平铺元素容易显得单薄，高级感来自以下克制的手法（全部不违反"零渐变零阴影"原则）：

1. **淡色几何衬底**：主体身后放 1-2 个极浅色几何形（5-8% 透明度的钴蓝/青绿大圆、淡雾蓝灰 #F5F7FA 大气泡），制造前后层次，画面立刻不"飘"。
2. **同色系深浅分层**：同一元素用品牌色的深浅两档（如藏蓝 + 淡藏蓝）做体积暗示，替代阴影。
3. **精致小细节**：稀疏点缀小星光（四角星）、小圆点、短弧线动感线，每个画面 3-5 处，宁少勿多。
4. **点阵/细线纹理**：局部用同色系细点阵或细线做肌理，只出现在背景或大面积色块内。
4.5. **扁平等轴视角（可选增强）**：主体面板/工作台可采用轻微斜俯视的等轴视图（flat isometric），保持扁平上色与描边不变，体量感明显更饱满、更"高级"，常见于豆包版封面；纯平视容易单薄时优先启用。
5. **明确视觉焦点**：一图一个焦点，焦点元素最大最完整，其余元素做引导（视线、路径、线条都指向焦点）。
6. **呼吸感排版**：元素间保持 1.5 倍以上的间距关系，边缘留白 ≥ 画面 10%。

## 六、构图规范

### 封面图（固定 2.35:1，建议 1800×766 或 900×383）
- **主题可读性（最高优先级）**：封面必须包含能**直接读出文章主题**的语义符号，抽象隐喻只是辅助。读者在缩略图（微信列表小图）上用 1 秒判断"这篇文章讲什么"。
  - 示例语义符号：认识/新品 → 软件面板、工作台、开箱；对比评测 → 天平、并排战列、分类分组；教程/步骤 → 箭头、路线、台阶；数据复盘 → 图表、增长、指标塔；痛点解决 → 伤口→愈合、锁→开。
  - 先写一句"缩略图测试声明"：如果我只能看到缩小成 200px 宽的图，我能说出文章讲什么吗？——不能就重写主题符号。
- **标题内嵌（不做后期叠加）**：标题文字**直接在生图环节渲染进封面**，作为构图的一部分，是本号的工作方式。
  - **位置与比例**：标题占左 1/3 区域（水平居中偏上或上对齐），主体画面占右侧 2/3；标题字号 ≥ 画面高度的 12%，缩略图下必须清晰可读。
  - **标题样式**：藏蓝(#2d3773)圆润无衬线粗体（与 Logo "Ai" 字标的圆润感一致）；标题结尾缀一颗珊瑚红(#FF5060)爱心作点睛；可用极浅雾蓝灰底块或藏蓝描边气泡字框加强标题区域，但不得喧宾夺主。
  - **主题副标签（可选）**：主体区域允许出现 1 个短主题词（≤ 4 字，如"AI工作台"）作产品名/主题标签，仅用于提升主题辨识度；文字必须精确指定、藏蓝圆润粗体、置于面板顶部或主体留白处，且不与其他文字冲突。
  - **字数限制**：主标题 ≤ 10 个汉字（AI 渲染中文越长越易错字）；长标题拆"主标题 + 短副标题"两行，或只渲染主标题。
  - **标题与主体的呼应**：标题旁边的视觉元素不重叠、不遮挡标题文字；标题区与主体区之间有自然的分界线（留白过渡）。
  - **生成后必检**：逐字核对标题文字，错字/糊字一律重生成（中文渲染优先 Nano Banana）。
- **缩略图可读**：主体轮廓必须在缩略图下仍能一眼辨认。
- **安全区**：重要元素不要贴边，上下各留 8% 边距（防止裁切）。

### 文章配图（比例按内容定：16:9 / 4:3 / 3:4 / 长图）
- 主体居中或按"从左到右"叙事流排布。
- 大留白，不加卡片边框、不加背景色块框。
- 长图/信息图类：纵向用留白分段，可用小气泡、圆点、细线做节奏分隔，不做重底色分区。

### 图表类配图（文章配图的主力形态）

公众号配图以表格、数据、流程为主，图表类配图遵守：

1. **图表即插画**：柱状图、折线图、饼图、时间轴不是截图，而是品牌风格的插画重绘——圆角柱、圆头折线、气泡化节点，全部藏蓝描边。
2. **数据诚实**：形状比例要忠实反映真实数据关系（高低、占比），只做风格化不做失真。
3. **小爱出镜**：小爱作讲解者（指向最高柱/关键节点）、庆祝者（站在终点/峰值旁），占画面 10-20%。
4. **焦点强调**：关键数据用珊瑚红点睛（爱心标记、圆点、小旗），其余用青绿/钴蓝/藏蓝。
5. **零文字原则的例外**：坐标轴、标签类信息**不在图内生成**，由后期排版叠加（AI 生成中文必乱码）；图内只留纯图形，需要标注的数据点用圆点或爱心占位。

### 品牌化表格配图（"数据表格直接展示"专用）

文章大量用到"表格内容"直接把数据陈列出来（报价表、对比表、清单），这类配图的正确形态是**表格转图**（AI 渲染真实表格内容），而不是插画化。规范：

1. **真实内容直接渲染**：把表格结构（表头 + 全部单元格文字）原样写进提示词，由 AI 渲染成图。渲染中文请优先 **Nano Banana**（文字还原最稳），豆包次之。
2. **内容规模控制**：全表 ≤ 40 字、单元格 ≤ 8 字最适合 AI 渲染；长表拆分为单列多行、或只取精华行（保留表头 + 重点行 + 语义完整即可）。
2.5. **信息密度**：表格外框占画面宽度 **≥ 85%**，上下留白 ≤ 8%——公众号配图突出信息本身，不做"画廊式"大片留白；提示词里写死"表格居中并尽可能占满画面宽度"。
2.6. **高亮行双重锚定**：AI 常数错行高亮。提示词必须同时给出"第 N 行"和"行内容关键词"（如：第三行标准版），并显式列出全部行顺序。
3. **品牌样式**（版本化参数，写死在提示词里）：
   - **外框**：对话气泡造型——藏蓝(#2d3773)粗描边 + 12px 大圆角 + 左下小弯钩尾巴（Logo 同款），白底。
   - **表头**：两种变体——A：深藏蓝底白字加粗；B：淡藏蓝(#E9ECF7)底藏蓝字加粗。
   - **表身**：白底，单元格分隔线用极淡藏蓝 rgba(45,55,115,0.10)；文字深灰 rgb(63,63,63)，无衬线中文，居中或按列语义对齐。
   - **重点行**：淡青绿或淡钴蓝（8% 透明度）整行高亮；点睛符号（珊瑚红爱心/圆点）只放 1 处。
4. **逻辑区内零装饰**：表格本身保持信息干净，不塞小爱、不塞气泡插画；装饰只可在表格外局部（气泡尾巴本身、表外角落 1-2 处小星光）。
5. **生成后必检**：逐字校对中文（AI 易错字/糊字）；错字多则缩小内容重生成；确保文字清晰不模糊，最终输出 2 倍像素（≥ 1600×900 对应 16:9）。

## 七、情绪与调性

- 关键词：**温暖、幽默、聪明、友好、轻盈**。
- 品牌定位：AI 很好玩，普通人也能上手。画面要"降低门槛感"，不要"炫技压迫感"。
- **隐喻优先**：技术概念一律翻译成生活化视觉隐喻（连接=桥/插头、学习=浇灌/爬台阶、多模态=长出眼睛、上下文=背包/书桌）。

## 八、负面清单（提示词必须排除）

- 禁止：渐变、投影/长阴影、3D 渲染、写实照片质感、厚涂质感。
- 禁止：霓虹色、荧光色、色板外任何色相。
- 禁止：复杂背景、密集细节、多主角抢戏。
- 禁止：画面内出现任何文字、字母、数字、水印、Logo（标题一律后期排版添加，避免中文乱码）。
- 禁止：直接复制或描摹任何公司官方 Logo / 吉祥物（用"联想色 + 原创角色"表达，如蓝鲸=DeepSeek、土拨鼠=Qwen 的思路，但造型必须原创）。
- 禁止：恐怖、暴力、嘲讽、焦虑暗示等负面情绪画面。

## 九、提示词骨架（所有提示词按此结构生成）

```text
【用途】微信公众号{封面图/配图}，{比例与像素}
【风格】现代扁平插画：纯白底（或极浅雾蓝灰底 #F5F7FA），所有元素带藏蓝色(#2d3773)圆润粗描边，手绘感不对称造型，无渐变无阴影，画面通透
【配色】严格四色体系：藏蓝 #2d3773（描边与深色块）、钴蓝 #2A6FF0（主角）、青绿 #1FC8C8（点缀）、珊瑚红 #FF5060（小面积点睛：爱心/圆点），辅以白色与浅灰；不出现其他颜色
【标题】{仅封面：精确标题文字、位置区域、字号与样式（藏蓝圆润粗体 + 珊瑚红爱心点缀）、与主体的关系}
【吉祥物】{此处原文粘贴第三节「小爱造型 DNA」段落，并说明小爱在画面中的动作与占比}
【场景】{生活化隐喻场景，一句话讲清}
【主体】{除小爱外的关键元素造型细节}
【高级感】{衬底几何形 / 深浅分层 / 小星光圆点点缀，本次用哪几种}
【构图】{封面：标题占左三分之一，主体占右侧三分之二；配图：居中/叙事流}
【文字约束】{表格/标题类图片：画面中只允许出现表格与标题文字，其余位置不得出现任何文字；插画类：画面中不要出现任何文字、字母、数字、水印或 Logo}
【排除项】{本次主题相关的具体排除项 + 通用负面清单要点}
```

写提示词的要点：
1. 场景隐喻先用一句话讲给"完全不懂技术的朋友"听，通了再写进提示词。
2. 颜色永远写"色名 + 色值"双保险（如"藏蓝色 #2d3773"）。
3. 排除项要针对本次主题具体化（模型容易画错什么就排除什么），不能只写通用清单。
4. 修图迭代时只追加修改点，前文保持不变（"保持其他内容不变，只把 XX 改为 XX"）。
